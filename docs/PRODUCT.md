# プロダクトメモ

## 現時点で決まっていること

- React + Vite を基本とする。
- スマートフォンで利用する Web アプリを想定する。
- AI を活用して継続的に開発する。

## 未決事項

- アプリの目的、対象ユーザー、主な利用場面
- 最初に提供する機能と優先順位
- データの保存先、認証の要否、外部サービスとの連携
- デザイン指針、ブランド、対応言語
- 配布方法、ホスティング、アクセス解析の要否

## 次の機能を決めるときのテンプレート

### 課題

誰が、どの場面で、何に困っているか。

### 利用者の操作

開始から完了までの操作を短く書く。

### 受け入れ条件

- 利用者が確認できる結果を列挙する。
- エラー時や空状態の表示も定義する。

### 決定事項と保留事項

決めた理由と、後で判断する項目を記録する。
