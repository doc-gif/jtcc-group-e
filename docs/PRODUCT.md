# プロダクトメモ

## 現時点で決まっていること

- React + Vite を基本とする。
- スマートフォンで利用する Web アプリを想定する。
- AI を活用して継続的に開発する。
- GitHub Pages に指示時のみ公開し、各バージョンを固定 URL と Release で残す。
- PR ベースで開発し、機能テストと UI/UX 基準の成功を自動承認・マージの条件にする。
- Apple HIG の Web に適用できる原則と、キャラクター／女性向けゲームの設計事例を UI/UX 基準に使う。具体的な世界観は今後決める。
- デザインは指定 Figma ファイルの JTCC App ページ群で管理する。ユーザー指定により、現在のアプリの緑系を維持する。初版の共通ルールと部品は `docs/DESIGN.md` を参照する。

## 未決事項

- アプリの目的、対象ユーザー、主な利用場面
- 最初に提供する機能と優先順位
- データの保存先、認証の要否、外部サービスとの連携
- 具体的な世界観・キャラクター・ブランド表現、対応言語
- アクセス解析の要否

## 次の機能を決めるときのテンプレート

### 課題

誰が、どの場面で、何に困っているか。

### 利用者の操作

開始から完了までの操作を短く書く。

### 受け入れ条件

- 利用者が確認できる結果を列挙する。
- エラー時や空状態の表示も定義する。

### 決定事項と保留事項

決めた理由と、後で判断する項目を記録する。
