# 内部検討用の素材ライブラリ

## AI が最初に開く場所

[Lastpiece｜サンリオ素材ライブラリ（内部検討用）](https://www.figma.com/design/MYYMoB2wL7LvA2oXZ2gxpT?node-id=0-1) を画像集の参照元とする。fileKey は `MYYMoB2wL7LvA2oXZ2gxpT`、ページは `0:1`。画面設計・デザインシステムの管理先は引き続き [DESIGN.md](DESIGN.md) の別ファイル。

## 配置済みの140枚

| ID | 内容 | 扱い |
| --- | --- | --- |
| W001–W100 | 公式キャラクター・世界観のイラスト、背景装飾100枚（60枚透過） | キャラクターや世界観の検討用 |
| P001–P020 | 公式ストアの実物グッズ写真20枚 | 商品写真。撮影背景を保持 |

対象はハローキティ、マイメロディ、クロミ、シナモロール、ポムポムプリン、ポチャッコ。レイヤーは ID・元画像・タイトルで探す。カードの公式出典URL、解像度、透過情報を確認する。

[限定グッズ棚 L001–L020](https://www.figma.com/design/MYYMoB2wL7LvA2oXZ2gxpT?node-id=5-2)（root `5:2`）に期間限定の実物商品20枚を配置済み。内訳はメロクロ周年イベント12枚、キキ＆ララ50周年4枚、クリスマス2025が4枚。各カードに説明、限定理由、公式イベント期間、当時の税込価格、公式発表リンク、copyrightを記録。期間はイベント開催期間であり、個別SKUの販売終了日・再販・現在在庫・仕入可否は未確認。

## 利用時の手順と制約

1. 用途に合う ID を Figma で探し、原画像と公式出典を確認する。キャラクターイラストと実物グッズ写真を取り違えない。
2. Figma の原画像を参照する。見本カードやプレビュー背景を画像に焼き込まない。無関係な汎用画像を混ぜない。
3. 採用候補には ID、node URL、公式出典、権利表記を残す。期間限定品は公式発表の販売期間と当時の参考価格を現在の販売状況と区別する。
4. この画像集は内部検討用。商用利用・一般公開の許可を意味しない。画像を公開リポジトリ、`public/`、公開プレビュー、本番へコピーしない。Figma の共有設定やデプロイ設定も変更しない。
5. Figma にアクセスできなければアクセス未確認と報告する。ローカルの manifest・CSV・images・ZIP は作成者の補助資料であり、他の作業者やクラウドAIが読める前提にしない。

公開アプリの既存オリジナル素材の運用は維持する。

### 例外: ピッチ用の実物グッズ写真（F15、担当者の許諾 2026-09-26）

- 範囲: **ピッチと関係者だけ**、**実物グッズの写真だけ**（L001 マイメロディ マスコット・L015 キキ＆ララ50周年 ポーチ・L011 メロクロ ガラケー風アクリルチャーム）。キャラクターの絵・世界観のイラスト（W001–W100）はアプリに入れない。
- 置き場所: Supabase `lastpiece-pitch` の非公開バケット `pitch-goods` だけ。担当者が Dashboard からアップロードし、開いているルームの参加者とホストだけが読める。リポジトリ・`public/`・確認用プレビュー・本番のビルドには入れない（上の 4 は変わらない）。手順は [PITCH_PHOTOS.md](PITCH_PHOTOS.md)、権限の確認は [SQL_MIGRATION_F15.md](SQL_MIGRATION_F15.md)。
- 権利表記: 各カードの copyright（L001・L011 は © 2024、L015 は © 2025）を写真の下に出す（`src/app/pitchPhotos.ts`）。
- 一般公開のデモ（HANDOFF の 7）に広げるのは、担当者が許諾の範囲を確かめてからの別の作業。画像の公開利用が必要な場合は、用途・権利・配布範囲が確定した別の指示として扱う。

### 例外: 限定公開アプリのキャラクターの絵（#144 案 D、#149）

- 範囲: **限定公開アプリ（開いているルームのホストと参加者）だけ**。一般公開アプリ・確認用プレビュー・リポジトリ・`public/`・ビルドには入れない（上の 4 は変わらない）。
- 置き場所: Supabase `lastpiece-pitch` の非公開バケット `pitch-characters` だけ。担当者が Dashboard からアップロードし、アプリは本人のログインで読む（公開 URL・署名付き URL は作らない）。場所と素材の対応・手順は [PITCH_CHARACTERS.md](PITCH_CHARACTERS.md)。成果物に入っていないことは `scripts/check-dist.mjs`（`pnpm build`）が確かめる。
