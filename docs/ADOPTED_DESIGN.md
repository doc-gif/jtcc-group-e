## 実装時の境界

- 配色はピンク基調の「さくらミルク」。見出し、戻る位置、免責文言「提案モック・公式サービスではありません」を群をまたいで揃える。`design-system/tokens.css` と `figma-manifest.json` は、2026-09-26 にマスターが参照する `Lastpiece v2` の変数へ整理した（[DESIGN.md](DESIGN.md)）。
- 色と文字（2026-09-26 の担当者の判断、F06 で Web に反映）: 主ボタンは `color/action/primary` `#be6482` の塗りに白文字、枠ボタンは白地に `#be6482` の枠と文字。どちらも文字スタイル `Lastpiece v2/Button`（19px 太字、Web は `1.1875rem`）。`#be6482` の文字はこの大きさ以上だけに使い、それより小さいピンクの文字は `color/accent/wine` `#a94a68` にする。下のタブの選択中はミント `#E3F1E7` の地にワインの文字、コイン札もミントの地にワイン。本文 `#172324`、補助文 `#52615a`。無効のボタンは `#d4dcd7` の地（枠ボタンは白地に `#d8c9cf` の枠）に補助文の色。Web はこれらを `src/index.css` のトークンと共通のボタン・タブの部品で持ち、画面ごとに色を書かない。
- T08/T09 の 500 コイン・9 種・棚 2/9・友だち・商品写真は説明用。T10 の人数の上限は担当者の判断（2026-09-26）で 100 人（ホスト込み）に変え、画面には出さない。サーバー・契約・状態層は F07 で 100 人に変えた。現行 Web の端末内 4 人デモと混同しない。
- T03 の [共有契約](SHARED_OPENING_CONTRACT.md)を真実の状態とする。結果は `startsAt` 前は全員非公開。公開後は保存済みの同じ結果を返す。見守り、満席復帰、予約の自動開始、二重請求防止はサーバー判定。ホストは担当者だけで、参加者によるホスト交代は廃止（ホスト用リンクでの再開に置き換え。サーバー・状態層は F10 で実装し、契約の `claim` は廃止した）。Figma の時間遷移は説明用で、実装タイマーの根拠にしない。
- 再接続の画面操作は最新ロビーへ戻す。開封後の自分の結果がサーバーの `myResults` にあるときだけ結果回収へ遷移する。「みんなの結果を見る」は結果公開後にだけ出す。
- 商品・キャラクター参照写真は内部 Figma のみに置く。公開コード、PR、プレビュー、Release に複製しない。権利者との関係、商品在庫、価格、当選保証、決済や発送を実サービスの事実として書かない。
- 実装時は 320px、文字200%、キーボード、Reduce Motion、実機セーフエリア、画面の待機・空・失敗・復帰を別途検証する。今回のマスター作成はその検証の代わりではない。
